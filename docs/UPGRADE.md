# Magidesk POS - Upgrade Guide

**Use this guide when the home office has sent a new update.**

---

## 1. Safety First (Do this!)

1.  **Close the App**: Make sure Magidesk POS is closed on **ALL** terminals in the store. Using the app during an upgrade can verify break things.
2.  **Backup**: Ask your manager: "Has the nightly backup run successfully?" Do not proceed if the answer is "No".

---

## 2. Installing the Update

1.  **Get the File**: Locate the new `MagideskInstaller.exe` file.
2.  **Run It**: Double-click the file on the **MAIN** terminal first.
3.  **Click Update**:
    *   The installer will detect that you already have the app.
    *   It might say "Upgrading Database...". This is normal. **Do not turn off the computer.**
4.  **Finish**: When the green bar finishes, click **Close**.

---

## 3. Verify it Works

1.  Open Magidesk POS.
2.  Log in with your PIN.
3.  Try to start a "Test Tab" and add one item.
4.  If that works, the upgrade is successful.
5.  **Repeat**: Now run the installer on all the other terminals.

---

## 4. Emergency Rollback (If it breaks)

**STOP.** If the app crashes immediately or you cannot take orders:

1.  **Do NOT** keep trying to fix it yourself.
2.  **Uninstall**:
    *   Go to Windows Settings -> Apps.
    *   Find "Magidesk POS" and click **Uninstall**.
3.  **Re-install Old Version**:
    *   Find the *previous* installer file (e.g., the one you used last month).
    *   Run it just like a normal install.
4.  **Call Support Immediately**: **555-0199**. Tell them "The upgrade failed and I am doing a rollback."

---

## Key Rules
*   **NEVER** turn off the computer while the installer is running.
*   **NEVER** upgrade during the dinner rush. Only upgrade before the store opens.
