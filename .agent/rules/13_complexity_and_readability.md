# Complexity and Readability

## Constraints
- Cyclomatic complexity must be kept low.
- Avoid deeply nested conditionals (>3 levels).
- Avoid long parameter lists (>5 parameters).

## Patterns
- Prefer composition over inheritance.
- Prefer explicit control flow over abstractions.

## Anti-Patterns (Forbidden)
- God objects
- Flag-driven behavior
- Implicit global state

Readable code is a functional requirement, not a preference.
